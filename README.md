
# Comparador de Textos

Proyecto académico desarrollado para UNISANGIL.

## Descripción

Aplicación web que permite comparar dos textos, identificar diferencias y revisar errores ortográficos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript moderno (módulos ES6)
- Node.js
- Express
- Bootstrap 5
- API LanguageTool
- LocalStorage y SessionStorage

## Funcionalidades

- Comparación de dos textos.
- Identificación de palabras iguales.
- Identificación de palabras eliminadas.
- Identificación de palabras agregadas.
- Revisión ortográfica.
- Sugerencias de corrección.
- Modo claro y oscuro.
- Almacenamiento local.
- Diseño adaptable a diferentes dispositivos.

## Instalación

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Instalar las dependencias:

   npm install

4. Iniciar el servidor:

   npm start

5. Abrir en el navegador:

   http://localhost:3000
